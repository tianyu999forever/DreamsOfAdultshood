# 相对于原版的修改

对照基准：项目中保留的 `Assets/Scenes/Mission1.unity` 及其原始公共脚本。

| 项目 | 原版 | 当前修改版 |
| --- | --- | --- |
| 核心解谜 | 收集至少 3 个数字、2 个运算符，组成算式；按结果与 12 的差距计分 | 收集字母，完成横竖交叉的英语填字；全部 8 个单词正确后通关 |
| 填字内容 | 无交叉填字 | COME、FROM、YOUR、MAKE、OF、HAVE、HER、HE；给出提示与大部分字母，仅留 4 个空格；交叉格共享同一枚字母 |
| 收集物 | 数字和运算符 | 共 9 枚字母，其中 O、R、A、E 为必需，其余 5 枚为干扰项；无需收集全部 |
| 地形 | 原有场景布局 | 重建为 20×20 格子迷宫，加入交错墙体通道、两组平台和缓坡，使用 Unity 内置几何体与材质 |
| 光照和背景 | 原场景光照及环境表现 | 调整方向光、环境光、天空背景和地面配色，关闭影响视线的光晕与后处理，并确保无雾 |
| 地图 | 原场景中的地图 | 新地图由关卡布局生成，同步墙、通道、平台、坡道、起终点、填字格，以及全部 9 枚字母的具体位置 |
| PLAN | 30 秒内观察、可自由移动并提前离开，超时失败 | 保留这些规则；地图改为与当前关卡同步的起点墙板，离开起点后隐藏 |
| 探索时限 | 原始 Mission1 场景序列化为 50 秒 | 调整为 90 秒，以适应新迷宫路线 |
| 地图照片 | 无此新机制 | 探索阶段按 Z 查看地图，每局一次、持续 5 秒，查看期间探索倒计时继续运行 |
| 背包与答题界面 | 数字/运算符背包及算式下拉框 | 字母背包、带编号的交叉棋盘、Across/Down 提示、错误反馈、重新选择及通关重开；收满 9 枚字母时所有选项均可见，上方另有完整字母清单 |
| 显示修复 | — | 修正入口提示反字；拾取字母面向玩家；地图以具体字母替代金色圆点；修复选项过窄及滚动条遮挡 |

保留 WASD 移动、鼠标视角、Shift 跑步、Space 跳跃、E 查看怀表、超时失败与重新开始。

修改关卡位于 `Assets/Mission6_Jizhijin/Scenes/Mission6_Jizhijin.unity`，并设为构建列表首场景。原版 `Mission1.unity` 及公共脚本、原收集物预制体等资源保留，关卡代码和生成资源集中在 `Assets/Mission6_Jizhijin/`。
