# 相对于原版的修改

对照基准：保留的 `Assets/Scenes/Mission1.unity` 及其原始公共脚本。

| 项目 | 原版 | 当前 Mission 6 |
| --- | --- | --- |
| 核心解谜 | 收集数字和运算符，组成算式 | 收集实体字母，填写横竖交叉的英语单词；交叉格共享同一枚字母 |
| 通过规则 | 原算式结果判定 | 第一关 10 个单词中至少 7 个正确；第二关 15 个单词中至少 11 个正确，允许部分空格不填 |
| 关卡结构 | 原场景布局 | 同一场景内连续两关；第一关完成后打开实体门，步行穿过通道进入第二关 |
| 地形 | 原场景地形 | 第一关 20×20、第二关 28×28；交错墙体、平台和缓坡，使用 Unity 内置几何体 |
| 收集物 | 数字、运算符 | 第一关 9 枚字母、7 个缺字格；第二关 18 枚字母、12 个缺字格，包含重复字母实体及干扰字母 |
| 评分 | 原算式相关分数 | 每关按单词正确率占 70%、通关速度占 30% 计算 S/A/B/C；最终显示两关成绩、总用时和平均分 |
| 时限 | 原 Mission1 探索 50 秒 | 第一关 180 秒、第二关 300 秒；从离开 PLAN 开始计时，答题和看照片也计时 |
| PLAN | 30 秒观察，可移动和提前离开；超时失败 | 每关保留该规则，墙上地图同步当前关卡 |
| 照片 | 无此道具 | Z 查看当前地图一次，持续 5 秒；进入第二关刷新一次机会 |
| 敌人 | 原 Mission1 无新哨兵系统 | 第二关两名 NavMesh 哨兵，巡逻、视线发现、追击、墙体遮挡、丢失目标恢复巡逻及近距离捕获；改编自 main 的 Mission2 敌人脚本 |
| 失败重试 | 重新开始 | 第二关失败可从第二关 PLAN 重试，保留第一关成绩；最终 PLAY AGAIN 重玩整个任务 |
| 地图 | 原地图 | 两张地图由对应关卡数据生成，显示墙、平台、坡道、起终点、填字格、全部字母及敌人初始位置 |
| 光照 | 原环境表现 | 调整方向光、背景和地面颜色，关闭影响视线的后处理与雾 |
| 界面 | 数字背包及算式选择 | 字母背包、带编号填字、英文提示、正确词数、评分预览、剩余时间；宽字母下拉列表支持滚动，按钮直接显示 |

保留公共移动、鼠标视角、跑步、跳跃、怀表、悬浮和面向相机等组件。所有关卡专用改动集中在 `Assets/Mission6_Jizhijin/`，原公共脚本及 Mission1 场景没有修改。敌人逻辑使用专用的 `Mission6_Enemy_Jizhijin`，没有覆盖 main 中的原脚本。

打开 `Assets/Mission6_Jizhijin/Scenes/Mission6_Jizhijin.unity` 即可游玩两关。当前评分规则和操作说明见 README，实测结果见 campaign-verification.txt。
